# 男性不育罕见病案例分享周-DNAAF3突变导“不动精子症”1例

> 更新时间：2026-09-17 (UTC+8)

1.“镜面人”小唐的苦恼
2024年9月，结婚仅三个月的小唐和他的妻子满怀期待，准备开始备孕的旅程。为了确保一切顺利，他们来到省妇幼生殖中心进行孕前检查。然而，就在问诊的过程中，史医生注意到了小唐那浓重的鼻音，显得颇为奇怪。于是，史医生决定为他开几个检查，其中包括精液常规和精子存活率的检测。

当结果出来时，小唐惊呆了：他的精子活力竟然为零，而精子的存活率却高达75%。面对这样的对比，史医生认真地询问他：“你是否一直有比较严重的鼻炎？而且即使用了药也没有什么好转？”小唐恍惚地点了点头。史医生继续说道：你可能患有“原发性纤毛功能障碍”，这种罕见疾病会影响呼吸道的健康，部分患者还会有导致精子活力异常，甚至是内脏逆位。小唐心中一震，支吾道：“没错，我就是个内脏逆位的‘镜面人’。”
2. 原发性纤毛功能障碍是个什么病？
原发性纤毛功能障碍（PCD），也叫纤毛不动综合征，是一种常染色体隐性遗传病，源于先天性的纤毛结构缺陷。它不仅导致呼吸道纤毛功能不全，使患者经常遭受慢性鼻窦炎、耳炎、支气管炎等症状，而且就在这些纤毛的背后，小唐的精子问题也悄然显现。精子的鞭毛与呼吸道纤毛结构相似，因此许多PFC患者精子活力极低，甚至有些人完全没有精子活力。这也就解释了为何小唐的精子活力会是零。为了更深入了解小唐的遗传学病因，史医生建议他进行全外显子检测。一个月后，当结果回到小唐面前时，报告显示他携带有DNAAF3基因的纯合突变。
3. 弱精子症的遗传学病因之一：DNAAF基因突变。
DNAAF（动力蛋白轴丝组装因子）家族在精子鞭毛的生成和功能中起着极为重要的角色。迄今为止，科学家们已发现15个DNAAF家族成员。这些蛋白质不仅关乎精子的结构，更影响其运动能力。DNAAF蛋白质的作用类似于构建鞭毛微管的工匠，确保精子形态完美。小唐所携带的突变位点，早在一名巴西的原发性纤毛功能障碍患者中就曾被记录过（Sci Rep. 2019 Jun 18;9(1):8693）。
DNAAF家族成员参与组装外动力蛋白臂的分子机制4. 卵泡浆内单精子注射技术帮助圆梦！
面对遗传检测结果，小唐感到无所适从。他不知道接下来该怎么办，是开始吃药，还是考虑试管婴儿？史医生温和地解释：“由于DNAAF3突变引发的弱精子症，药物治疗并不推荐，因为根本问题在于基因突变，目前没有任何已知药物可以修复这个缺陷。”然而，史医生很快又给小唐带来了希望。“在2023年，我国的研究团队成功报道了一名同样携带DNAAF3基因突变的患者，经过卵泡浆内单精子注射（ICSI）治疗后，成功怀孕了。这表明，DNAAF3基因变异导致的不动精子症患者是可以借助ICSI技术实现生育的愿望。”经过细致的讲解和考虑，小唐夫妇最终决定尝试试管婴儿助孕。治疗顺利进行，一枚第五天的囊胚顺利移植。就在他们满怀期待之际，终于收到了喜讯——小唐的妻子成功怀孕了！
